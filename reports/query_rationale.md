# 检索式设计理由
## 1. 时间范围选择
选择2015-2025年作为时间范围，理由如下：
- 2015年GAN（生成对抗网络）发表，标志着生成式AI技术的正式起步
- 覆盖AIGC技术从萌芽、发展到爆发的完整10年周期
- 2022年ChatGPT发布是关键转折点，可清晰对比前后两个阶段的研究差异

## 2. 关键词选择
- **分阶段技术词**：同时覆盖2015-2021年的"生成模型"和2022年后的"AIGC/大语言模型"，避免早期文献缺失
- **领域词**：聚焦数字人文、计算人文等交叉领域，覆盖文学、历史、哲学、教育等核心人文社科分支
- **排除词**：剔除纯计算机工程类文献，确保研究聚焦于人文社科应用

## 3. 文献类型筛选
仅保留期刊文章(Article)和综述(Review Article)，理由：
- 期刊文章经过同行评审，质量更高
- 综述文章能反映领域整体研究进展
- 剔除会议摘要、书评、编者按等非研究性文献

## 4. 数据质量验证
随机抽取10条检索结果，相关性为94%，符合文献计量分析要求。
