# AI工具使用说明

## 一、使用原则
本项目严格遵循学术诚信与透明披露原则，所有AI工具仅作为辅助工具使用，不替代人工研究与决策。核心研究设计、数据处理、结论推导、学术观点均由项目团队独立完成，AI生成的所有内容均经过人工逐行校验、修改与确认，确保内容的准确性与原创性。

## 二、使用的AI工具及版本
| 工具名称 | 版本/类型 | 主要用途 |
|----------|-----------|----------|
| 豆包大模型 | 在线版 | 学术文本润色、代码逻辑排查、文档结构优化 |
| GitHub Copilot | 在线版 | Python脚本补全、语法纠错、注释生成 |
| CiteSpace | 6.4.R2 | 文献计量可视化（专业科研工具，非生成式AI） |

## 三、各研究环节AI使用明细
### 1. 数据处理与代码开发环节
- 使用AI辅助编写Python数据清洗、格式转换、统计表格生成脚本的基础框架与语法校验
- 使用AI排查代码运行报错、优化脚本可读性与注释规范
- **核心数据处理逻辑、筛选规则、参数设置均由团队人工制定并验证**，所有脚本运行结果均经过人工抽样核对

### 2. 学术写作与文档环节
- 使用AI对论文初稿进行语言润色、句式优化，提升学术表达的严谨性与流畅度
- 使用AI辅助梳理README文档结构、统一排版格式
- 使用AI辅助生成部分说明性文字的初稿，所有专业表述、研究结论、结果解读均由团队人工改写与确认
- **核心研究观点、结果分析、讨论部分均为团队独立撰写，AI仅做语言层面优化**

### 3. 可视化与成果整理环节
- 使用AI辅助优化图表说明文字的表述逻辑
- 使用AI辅助整理仓库目录结构与文件说明
- **所有知识图谱均由CiteSpace基于真实文献数据生成，AI未修改任何可视化结果与数据**

## 四、人工审核与质量控制
1.  **事实核验**：所有AI生成的文本内容，均由团队成员核对数据来源、学术概念与事实表述，杜绝AI幻觉内容
2.  **逻辑校验**：对AI辅助编写的代码，逐行验证运行结果与预期逻辑的一致性，确保数据处理准确无误
3.  **原创性确认**：所有核心研究结论、学术观点、分析框架均为团队独立产出，AI未参与核心研究设计与推导
4.  **最终审核**：项目所有交付成果均由组长进行最终人工审核，确认内容合规、准确、符合学术要求

## 五、责任声明
本项目团队确认，AI工具的使用严格遵守课程学术规范要求，所有披露内容真实完整。项目成果的学术责任由全体团队成员共同承担，AI工具不具备作者身份，不承担任何学术责任。
